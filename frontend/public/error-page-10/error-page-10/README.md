# Error Page V10 | Colorlib

A free HTML snippet from Colorlib. Open `index.html` in a browser -- there is
nothing to install and nothing to build.

## What's inside

    index.html        the markup
    css/style.css     every style this snippet uses
    js/snippet.js     the behaviour, in plain JavaScript
    fonts/            the webfonts it references, as woff2
    images/           its images

## Dependencies

None. No jQuery, no Bootstrap, no build step, no CDN call. Everything the
snippet needs is in the folder, so it renders the same offline, behind a
firewall, or ten years from now.

## Using it inside a Bootstrap project

It drops straight in. The snippet carries its own styles rather than expecting a
framework, so it renders identically whether the host page loads Bootstrap 4, 5,
6 or nothing at all, and it will not be restyled by a Bootstrap upgrade.

Its class names are its own and namespaced, so they will not collide with yours.
If your page already sets a global `box-sizing` or type scale, load
`css/style.css` after your framework.
