# HIS Archives — Backend

API Laravel de l'application HIS Archives (Hetep Iaout Services).

Voir le [README à la racine du dépôt](../README.md) pour l'installation complète, les commandes de développement et le déploiement — ce dossier ne contient que le code de l'API (auth JWT, documents, PAI, notifications, jetons API...).

## Commandes utiles propres au backend

```bash
composer install              # dépendances PHP
php artisan migrate --seed    # base de données
php artisan test               # suite de tests
```
